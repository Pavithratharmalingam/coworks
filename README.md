# Coworking System – Responsive Website

## About the Project
Developed a responsive multi-page coworking website that promotes teamwork, collaboration, and productive work environments. The website provides information about coworking services, team activities, and collaboration opportunities through an interactive and user-friendly interface.

🔗 **Live Demo:** (https://coworks-8c605.web.app)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase Hosting

## Features
- Responsive multi-page website (`index.html`, `Service.html`, `contact.html`).
- Interactive navigation bar with dropdown menus and a mobile-friendly hamburger menu.
- Team collaboration and coworking service sections.
- Team categories including Software Development, Testing, Web Development, and Data Analytics.
- Idea sharing, problem-solving, task sharing, and feedback sections.
- Contact form with client-side validation using conditional statements and Regular Expressions.
- Local Storage and JSON methods to store validated form data.

## Key Functionalities
- Interactive navigation using JavaScript.
- Responsive layout using CSS media queries and Bootstrap 5.
- Client-side form validation with Regular Expressions.
- Data handling and persistence using `localStorage` and `JSON`.


## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder in Visual Studio Code.
3. Navigate to `public/index.html` and open it using **Live Server** to view the website in your browser.
